Gaps & critical misses (what’s blocking “any and all GEDCOMs”)

Encodings & ANSEL: No ANSEL decoding or robust encoding detection; UTF-8 assumptions will break many legacy files.

GEDZIP / media: No *.gdz container support; OBJE/media checksums, mime detection, and safe extraction not wired.

GEDCOM 7.x: No 7.x profile or compatibility layer; only 5.5/5.5.1 tags schema is visible.

Validator: No centralized standards validator with rule IDs/severity/fix-its; validations are implicit and scattered.

Cross-ref integrity: Need a pointer graph to catch duplicate/dangling xrefs and ensure FAMC/FAMS reciprocity.

Round-trip writer: JSON export exists, but GEDCOM writer (5.5.1/7.0) is missing—can’t prove fidelity.

Persistence & interop: No Postgres schema/export; Neo4j integration is not present (no CSV/Cypher emitters).

Place/date completeness: EDTF coverage (dual-dating, ranges, approximations) and place jurisdiction planning need to be fully implemented and tested.

Performance & streaming: Tokenizer doesn’t enforce memory bounds for very large inputs; no chunked streaming.

Privacy: No living-person filter/redaction policy included.

Repo hygiene: .venv committed; need pyproject.toml, linters (Ruff), type checks (MyPy), pre-commit.
